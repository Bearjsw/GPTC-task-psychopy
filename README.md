# GPTC 행동 선행실험 · 본 과제

정보원 여섯이 제품을 골라 주면 참가자가 그걸 사겠는지 정하는 과제다.
사전·사후 설문은 구글 설문으로 받고, PsychoPy는 과제만 돌린다.

## 두 판

제품 리스트가 다른 두 판이 있다. 코드는 거의 같고 읽는 자극 폴더와 설계
숫자만 다르다. 어느 쪽으로 갈지는 아직 안 정했다.

| | 기존판 | 0818 리스트판 |
|---|---|---|
| 실행 | `GPTC_task.py` | `GPTC_task_0818.py` |
| 자극 | `stim/` | `stim_0818/` |
| 제품군 | 8개 | 21개, 대분류 7개로 묶임 |
| 본 과제에 쓰는 제품군 | 7개 | 21개 |
| 시행 | 7제품군 x 3세트 x 2회 = 42 | 21제품군 x 1세트 x 2회 = 42 |
| 정보원당 | 7시행 | 7시행 |
| 결정 국면 | 특징 3줄 | 요약 문장 1줄 (UT판/HE판) |
| 연습 | 바람막이로 4시행 | 바람막이로 4시행 |
| 소요 | 약 16분 | 약 16분 |
| 검사 | `tools_check_design.py` | `tools_check_design_0818.py` |
| 미리보기 | `tools_preview.py` | `tools_preview_0818.py` |

웹에서 돌리는 판도 같은 두 벌로 [`web/`](web)에 있다. 아래 **웹판**을 본다.

0818판의 자극은 `0818_product_list.xlsx`가 원본이다. 문구를 고쳤으면 엑셀을
고치고 `python tools_import_0818.py`로 `stim_0818/`을 다시 만든다.

아래 설명은 기존판 기준이다. 0818판에서 달라지는 곳은 위 표에 있다.

## 진행 순서

```
1) 구글 설문 (사전)   정보원 소개문 학습 · 제품군 관심도
2) PsychoPy 과제      python GPTC_task.py      약 16분
3) 구글 설문 (사후)   유사도 -> 국면 A -> 간섭 -> 국면 B -> 처리 동기 -> 조작 점검
```

셋을 참가자 ID로 잇는다. 문항은 [`구글설문_문항/`](구글설문_문항)에 있다.

참가자 ID는 연번으로 준다. 국면 평정 순서를 ID 끝자리 홀짝으로 가르기 때문에
무작위 문자열을 쓰면 절반씩 안 나뉜다.

## 실행

```
python GPTC_task.py                실제 진행
python GPTC_task.py --windowed     창 모드로 화면만 확인
python GPTC_task.py --record 이름  자동 진행을 4배속 영상으로
```

0818판은 `GPTC_task_0818.py` 로 바꿔 넣으면 된다.

터미널을 안 열려면 폴더에서 이 둘 중 하나를 더블클릭한다. 검은 창이 뜨고
바로 과제가 시작되니 참가자 앞에서 열지 않는다.

```
실행_기존판.bat        GPTC_task.py
실행_0818판.bat        GPTC_task_0818.py
```

PsychoPy 스탠드얼론이면 Coder에서 열고 Run 해도 된다.
실행 창에서 받는 것은 참가자 ID, 연령, 성별 셋뿐이다. 양쪽 판 다 같다.

돌아가는 모습은 [`GPTC_task_시연.mp4`](GPTC_task_시연.mp4)에 있다.

## 웹판

PsychoJS로 옮긴 판이 [`web/`](web) 아래 있다. 파이썬판과 화면도 순서도 같다.
브라우저는 파일을 로컬에 몰래 못 쓰므로, 과제가 끝나면 참가자 ID로 된 CSV가
**내려받기 폴더에 떨어진다.** 그 파일을 연구자가 받아 두면 된다.

```
실행_웹_기존판.bat      제품군 8개  http://127.0.0.1:8731
실행_웹_0818판.bat      제품군 21개 http://127.0.0.1:8732
```

누르면 검은 창이 하나 뜨고 브라우저가 열린다. 그 창이 자리를 지키는 동안만
과제가 돌아가니 끝날 때까지 닫지 않는다. 창을 닫으면 서버가 내려간다.

주소 뒤에 `?windowed`를 붙이면 전체화면 대신 창으로 뜬다. 화면만 볼 때 쓴다.

라이브러리는 전부 [`web/lib/`](web/lib)에 받아 두었다. 실험 중에 바깥으로
나가지 않으니 인터넷이 끊겨도 돌아간다.

**파이썬판과 배치가 같지는 않다.** 파이썬의 난수기를 자바스크립트에서 그대로
재현할 수 없어서, 같은 참가자 ID를 넣어도 브랜드명과 순서가 다르게 나온다.
각 판 안에서는 ID가 같으면 같은 배치가 나온다. 한 연구에서는 한쪽만 쓴다.

자극 CSV를 고쳤으면 `python tools_build_web_stim.py`를 돌려야 웹판에 반영된다.
설계 검사는 `node tools_check_design_web.mjs`.

## 한 시행

```
고정점 (0.5~1.5초 지터)
정보 국면 7.5초  [다수 의견]
                 Pufano 백팩  -  정장에도 어울리는 형태
                 Naudrut 백팩  -  네 가지 색상 구성
                 Geanat 백팩  -  노트북 전용 칸
  + 평정 1~7     "이 중에 구매할 만한 게 있어 보입니까?"
고정점
결정 국면 6초    [다수 의견] / Geanat 백팩 / 38,000원 / 상세 3줄
  + 구매한다 · 구매하지 않는다
  + 평정 1~7     "얼마나 구매하고 싶습니까?"
```

좌우 키로 옮기고 Enter로 확정한다. `Esc`를 누르면 멈추고, `N`이면 이어서
하고 `Y`면 끝낸다.

## 설계

```
시행 수 = (제품군 8 - 연습 전용 1) x 세트 3 x 반복 2 = 42,  정보원당 7시행
```

- 같은 후보 세트가 딱 두 번 나온다. 두 번 다 화면이 글자 그대로 같고
  정보원 라벨만 바뀐다
- 추천 제품이 화면 몇 번째 줄에 있었는지가 정보원마다 고르게 나뉜다
- 같은 정보원이나 제품군이 3연속으로 나오지 않는다

브랜드와 특징의 짝, 화면 순서, 가격은 참가자마다 새로 뽑는다. 무작위화는
참가자 ID로 시드를 고정해서, 같은 ID면 같은 배치가 나온다.

## 자극

[`stim/`](stim) 아래 CSV 네 개가 전부다. 엑셀로 정리한 사본은
[`GPTC_자극목록.xlsx`](GPTC_자극목록.xlsx).

| 파일 | 내용 |
|---|---|
| `sources.csv` | 정보원 6종 |
| `categories.csv` | 제품군 8개와 가격 범위 |
| `details.csv` | 특징 48개 (제품군당 실용 3 + 감성 3) |
| `brands.csv` | 브랜드명 150개 |

브랜드명은 자음과 모음이 번갈아 오는 구조로 만들어 전부 읽힌다. 참가자마다
이 목록에서 72개를 다르게 뽑아 쓴다. 목록을 다시 뽑으려면
`python tools_make_brands.py`.

**새로 뽑았으면 사람이 한 번 훑어야 한다.** 어색하거나 뜻이 읽히거나 불쾌한
행을 지우면 된다. 72개 이상 남으면 실험은 돌아간다.
